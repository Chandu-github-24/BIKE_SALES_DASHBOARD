# 🚴 Bike Sales Dashboard | Microsoft Excel

## 📌 Project Overview

This project showcases an interactive **Bike Sales Dashboard** built using **Microsoft Excel**. The objective was to transform raw bike sales data into meaningful business insights through data cleaning, analysis, and visualization.

The dashboard enables users to explore customer purchasing patterns based on demographic and regional factors using interactive slicers and Pivot Charts.

---

## 🎯 Objectives

- Clean and organize raw sales data.
- Analyze customer purchasing behavior.
- Build an interactive dashboard for decision-making.
- Present insights using dynamic visualizations.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Conditional Formatting
- Dashboard Design

---

## 📊 Dashboard Features

The dashboard provides insights into:

- 🚲 Bike Purchases by Commute Distance
- 👨‍💼 Average Income by Gender
- 👥 Bike Purchases by Age Bracket
- 🌍 Region Filter
- 🎓 Education Filter
- 💍 Marital Status Filter

Interactive slicers allow users to filter the dashboard dynamically and analyze customer trends.

---

## 📈 Key Insights

- Customers with shorter commute distances tend to purchase more bikes.
- Middle-aged customers represent the highest number of bike purchases.
- Higher average income groups show greater purchasing potential.
- Purchasing behavior varies across education levels, marital status, and regions.
